OpenJevSwift documentation

A native Swift implementation of OpenJev, the open, Jev-compatible "System One" decision server. Send a state and typed questions; every answer is read from a model's probabilities rather than generated as text: the probability of yes, or of every option with a confidence.

Modules

  • OpenJevCore

    The decision engine: Jev's request and answer types, the prompts and canvases, and the engines that answer a request through a model backend. macOS, iOS and Linux.

  • OpenJevEncoders

    Verdict and Laya on Core ML, in an app on an iPhone or a Mac, or behind the server.

  • OpenJevLetterReadout

    JevK5 on MLX, Alibi Serikbay's letter-readout model, in an app or behind the server.

  • OpenJevDiffusionGemma

    DiffusionGemma 26B-A4B on MLX for Apple silicon Macs: the model, its download and its runtime.

  • OpenJevServer

    The Jev-compatible HTTP server behind openjev serve, with every OPENJEV_* setting.
