# Adopters

Organizations that use OpenJevSwift, each added by the organization itself.

To add yours, open a pull request that adds one row to the table below:

- **Organization:** its name, linked to its website if you like.
- **What it uses OpenJevSwift for:** one sentence, such as the server with Verdict behind a support
  queue, or the libraries in an iOS app.
- **Link:** a public page about that use, such as a blog post or a case study, or `-` when there is
  none.

Keep the rows in alphabetical order by organization. Add or change only your own organization's
row; the pull request should come from someone who works there.
